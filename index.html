PROTECTION DES DONNÉES

Sauvegarde et restauration

Exporte une copie JSON de tes projets, notes, étapes, actions, dépenses, disponibilités et séances. Le JSON contient les données uniquement. Le ZIP complet inclut aussi les pièces jointes et permet leur restauration.

Enregistre les archives sur ton PC. La création du ZIP nécessite Internet, un espace disque suffisant et peut être longue pour les gros fichiers.

Aucune sauvegarde enregistrée dans ce navigateur.

Restaurer les éléments manquants

Cette restauration n’écrase pas les enregistrements existants. Elle n’efface rien. Elle nécessite une connexion et peut ajouter des projets.

Attention : une restauration interrompue peut être partielle. Le réimport d’un même fichier saute les éléments déjà présents. Vérifie le résultat après l’opération.
